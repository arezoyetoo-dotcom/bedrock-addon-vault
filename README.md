## 🚀 How to Install (.mcaddon)

1. **Tap Download:** Download any `.mcaddon` file from the showcase portal or repository.
2. **Open with Minecraft:** Tap the downloaded file in your browser downloads or Files app. Minecraft will automatically launch and import the pack.
3. **Activate in World:**
   - Go to **World Settings** ➔ **Behavior Packs** (and **Resource Packs** if included).
   - Activate the pack.
   - Under **Experiments**, toggle on **Beta APIs** (required for Bedrock Script API mods).
   - Enjoy your enhanced Bedrock experience!
